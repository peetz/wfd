# What's For Dinner?

## Goal

Help households decide what to eat using a fair voting system in Home Assistant.

## Version 1.0

WFD v1.0 is the distributable core release and includes:

- Meal library management
- Household voters backed by Home Assistant Persons
- Private voting rounds
- Deterministic explainable decision engine
- Historical round persistence and results
- Home Assistant services and lifecycle events
- Home Assistant application panel

## Future

V1.1 work is tracked in GitHub issues and includes notifications, richer history analytics, frontend polish, and expanded automation APIs.

Longer-term ideas include shopping lists, AI suggestions, and pantry integration.
